# Non-symmetric Vector Dyson Equations — Lean 4 Formalization

A Lean 4 / Mathlib formalization accompanying the manuscript **Non-symmetric Vector Dyson Equations** by **Jiaoyang Huang, Zhonggen Su, and Ruizhe Xu**.

**Verification scope.** The paper-facing conclusions are formalized in Lean 4 **conditional on explicitly stated general mathematical hypotheses**. Some results from spectral theory, Stieltjes theory, algebraic and analytic function theory, Perron–Frobenius theory, and perturbation theory are supplied as theorem arguments rather than proved within this repository. A successful `lake build` or axiom audit checks the resulting conditional Lean declarations; it **does not establish the external hypotheses or automatically certify agreement with every statement in the manuscript**. See [External arguments](EXTERNAL_ARGUMENTS.md) for the assumptions and [Manuscript versions and formalization fidelity](#manuscript-versions-and-formalization-fidelity) for the relationship between the two TeX sources and the Lean formalization.

## Mathematical setting

We consider the nonsymmetric vector Dyson equation

$$
-\frac{1}{m_i(z)}=z-a_i+\sum_{j=1}^d s_{ij}m_j(z),
\qquad z\in\mathbb{C}_+,\quad S=(s_{ij})\geq0,
$$

with a nonnegative finite matrix $S$ that need not be symmetric. The manuscript analyzes canonical solutions, representing measures, boundary regularity, regular edges and cusps, and linear and nonlinear stability in the symmetric and non-backtracking settings.

## Manuscript versions and formalization fidelity

The [`source/`](source/) directory contains **two versions of the same manuscript**, retained to document the relationship between the original paper and the statements used in the formalization:

- [`main-article-1014.tex`](source/main-article-1014.tex) is the **original supplied manuscript**, preserved without modification. The main results and labeled statements are indexed against this version.
- [`main-article-1014.formalized.tex`](source/main-article-1014.formalized.tex) is a **minimally clarified version** of that manuscript. It makes certain qualifications explicit where the original wording would otherwise be inaccurate or too broad. It is not a separate paper and is not itself a Lean proof.

The changes are localized: the universal cover of a finite tree need not be infinite; reducible-matrix blocks may introduce complex, spectral-parameter-dependent effective forcing; the nonlinear-stability statement (M7) specifies dependence on a previously fixed positive height parameter; and the bipartite-origin inverse estimate is asserted on a possibly smaller neighborhood. These clarifications are discussed in [FIDELITY_REVIEW.md](FIDELITY_REVIEW.md), and a direct line comparison can be obtained with `diff -u source/main-article-1014.tex source/main-article-1014.formalized.tex`.

The clarified TeX is the closer **statement-level reference** for those corrected assertions, but the **precise formal claims are the types of the Lean declarations**, including all of their explicit hypotheses. Neither TeX document is automatically converted into or mathematically verified by Lean. The verification script also uses the two source files for manuscript-version tracking. See [`source/README.md`](source/README.md) for a concise explanation alongside the TeX files.

## Build and verification

The project pins Lean 4.24.0 and a specific Mathlib commit through [`lean-toolchain`](lean-toolchain), [`lakefile.toml`](lakefile.toml), and [`lake-manifest.json`](lake-manifest.json).

```bash
lake exe cache get
lake build
python3 scripts/verify.py
```

The last command checks the project sources and generates theorem-signature, global-axiom, and proof-route audit reports in `validation/`. For the main statements only:

```lean
import Dyson.Paper.Main
```

The [GitHub Actions workflow](.github/workflows/lean.yml) builds the project on pushes and pull requests to `main`, and can also be started manually. Upon a completed run, its **Artifacts** section contains fresh audit logs. A green workflow status certifies that the configured build and audits succeeded; it does not prove the external mathematical hypotheses.
