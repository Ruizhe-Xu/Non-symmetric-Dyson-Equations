# Manuscript sources and their relation to the Lean formalization

This directory contains two TeX versions of **the same manuscript**, *Non-symmetric Vector Dyson Equations*. They are retained for reference and statement tracking; neither is itself a Lean source file.

| File | Role |
|---|---|
| [`main-article-1014.tex`](main-article-1014.tex) | Original supplied manuscript, preserved unchanged. This is the primary manuscript used for indexing the main results and labeled statements. |
| [`main-article-1014.formalized.tex`](main-article-1014.formalized.tex) | Minimally clarified version used to express a small number of statements and background remarks more precisely in connection with the formalization. It is **not a separate paper**. |

## Local clarifications in the second version

1. **Universal cover.** A finite graph's universal cover is a tree, but it is not necessarily infinite: the universal cover of a finite tree is that finite tree.
2. **Reducible matrices.** Triangularizing by strongly connected components may produce zero singleton blocks and complex, spectral-parameter-dependent forcing from previously solved blocks. The irreducible real-potential results cannot automatically be applied recursively without checking their hypotheses.
3. **Nonlinear stability (M7).** The relevant constants and neighborhoods may depend on a previously fixed positive height parameter `η₀` and the fixed regular spectral regions; the statement does not claim uniformity as that parameter tends to zero.
4. **Bipartite-origin inverse bound.** The two-sided estimate is made on a possibly smaller neighborhood with `0 < r ≤ ε`, with the specified upper-half-plane boundary condition, rather than on an arbitrary originally chosen neighborhood.

For the exact modifications, compare the files line by line:

```bash
diff -u source/main-article-1014.tex source/main-article-1014.formalized.tex
```

## Scope of formal verification

The Lean formalization, found under [`../Dyson/`](../Dyson/), is based on the supplied manuscript and its necessary clarifications. The exact Lean theorem types, **including explicit external mathematical hypotheses**, determine what is mechanically checked. The two TeX files are used for provenance and version tracking by the repository's verification scripts; they are **not automatically parsed or proved by Lean**.

For a detailed discussion of the differences and proof dependencies, see [`../FIDELITY_REVIEW.md`](../FIDELITY_REVIEW.md) and [`../EXTERNAL_ARGUMENTS.md`](../EXTERNAL_ARGUMENTS.md). The Lean code was generated by **ChatGPT (OpenAI)**, as explained in [`../README.md`](../README.md).
